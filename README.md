# Downloader Bot

Telegram downloader bot starter: Python + aiogram + yt-dlp + FFmpeg.

## Ishga tushirish

1. `@BotFather` orqali bot oching.
2. `.env.example` ni `.env` qilib nusxalang.
3. `BOT_TOKEN`, `ADMIN_ID`, `FORCE_CHANNEL` ni kiriting.
4. `pip install -r requirements.txt`
5. `python bot.py`

## Admin
Botga `/admin` yuboring. Admin ID `.env` dagi `ADMIN_ID` bilan bir xil bo'lishi kerak.

## Render
Dockerfile mavjud. GitHub repository'ni Render Web Service sifatida deploy qilish mumkin.

## Eslatma
Downloader faqat platforma qoidalari va mualliflik huquqiga zid bo'lmagan, yuklashga ruxsatingiz bor kontent uchun ishlatilishi kerak.
